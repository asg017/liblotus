# lotus-wasm

WASM bindings for the `lotus-core` spreadsheet engine, built with [wasm-bindgen](https://rustwasm.github.io/wasm-bindgen/).

This crate provides a thin JavaScript/TypeScript wrapper around the pure-Rust spreadsheet engine, letting you run formula parsing, evaluation, and DAG-based recalculation directly in the browser or Node.js.

## Prerequisites

Install [wasm-pack](https://rustwasm.github.io/wasm-pack/), the tool that compiles Rust to WASM and generates JS/TS glue code:

```sh
cargo install wasm-pack
```

## Building

From the `rust/crates/lotus-wasm` directory:

```sh
# For use with <script type="module"> or bundler-free ES module imports
wasm-pack build --target web

# For use with a bundler (webpack, vite, etc.)
wasm-pack build --target bundler

# For use in Node.js (CommonJS)
wasm-pack build --target nodejs
```

After building, a `pkg/` directory is created containing:

- `lotus_wasm_bg.wasm` — the compiled WASM binary
- `lotus_wasm.js` — JavaScript glue code
- `lotus_wasm.d.ts` — TypeScript type definitions
- `package.json` — so you can `npm link` or publish the package

## Usage

### Browser (ES module / `--target web`)

```html
<script type="module">
  import init, { WasmSheet } from './pkg/lotus_wasm.js';

  await init();

  const sheet = new WasmSheet();

  // Set cells: pass a JSON array of [cell_id, raw_value] pairs
  sheet.set_cells(JSON.stringify([
    ["A1", "10"],
    ["A2", "20"],
    ["A3", "=A1+A2"],
  ]));

  console.log(sheet.get("A3")); // "30"
  console.log(sheet.get_all()); // '{"A1":"10","A2":"20","A3":"30"}'

  // One-shot evaluation without cell context
  console.log(WasmSheet.evaluate("=2^10")); // "1024"

  sheet.free(); // release WASM memory when done
</script>
```

### Bundler (webpack, vite, etc. / `--target bundler`)

```js
import { WasmSheet } from 'lotus-wasm';

const sheet = new WasmSheet();
sheet.set_cells(JSON.stringify([["A1", "=SUM(1,2,3)"]]));
console.log(sheet.get("A1")); // "6"
```

### Node.js (`--target nodejs`)

```js
const { WasmSheet } = require('lotus-wasm');

const sheet = new WasmSheet();
sheet.set_cells(JSON.stringify([["B1", "hello"], ["B2", "=B1"]]));
console.log(sheet.get("B2")); // "hello"
```

## API Reference

### `new WasmSheet()`

Creates a new empty spreadsheet.

### `sheet.set_cells(changes_json: string): void`

Apply a batch of cell changes. The argument must be a JSON-encoded array of `[cell_id, raw_value]` pairs.

- Formulas start with `=` (e.g., `"=A1+B1"`, `"=SUM(A1:A10)"`)
- Plain numbers and strings are treated as literal values
- Setting a cell's value to an empty string `""` deletes it

Throws on invalid JSON or circular dependencies.

```js
sheet.set_cells(JSON.stringify([
  ["A1", "100"],
  ["A2", "=A1*2"],
]));
```

### `sheet.get(cell_id: string): string`

Returns the computed value of a single cell as a string. Returns `""` for empty/unset cells.

```js
sheet.get("A2"); // "200"
sheet.get("Z99"); // ""
```

### `sheet.get_all(): string`

Returns a JSON string containing all computed cell values. Empty cells are omitted.

```js
JSON.parse(sheet.get_all());
// { "A1": "100", "A2": "200" }
```

### `WasmSheet.evaluate(formula: string): string` (static)

One-shot formula evaluation with no cell context. Cell references resolve to empty. Useful for calculator-style expressions.

```js
WasmSheet.evaluate("=2+3");        // "5"
WasmSheet.evaluate("=(10-2)*4");   // "32"
WasmSheet.evaluate("=SUM(1,2,3)"); // "6"
```

## Notes

- The `pkg/` directory is generated by `wasm-pack build` and should generally be git-ignored.
- For production use, pass `--release` to `wasm-pack build` for optimized output.
- Memory management: call `sheet.free()` when you are done with a `WasmSheet` instance to release the WASM memory. In most applications this is only necessary if you create and discard many instances.
