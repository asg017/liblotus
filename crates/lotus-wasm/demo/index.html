lotus-wasm · custom cell types

Click a cell, type a value, press Enter. Pre-registered handlers: polygon, money, color. Try #ff8833, $100, POLY:[[0,0],[4,0],[4,3],[0,3]], =A1+A2.

handlers

polygon — POLY:[[x,y], …]
Function: =AREA(ref) via shoelace formula.
money — $100 or $1.50
Intercepts + / -; same-currency only.
color — hex like #ff8833
Displays a swatch; = compares by canonical RGB.

starter grid

A1: POLY:[[0,0],[4,0],[4,3],[0,3]]
A2: =AREA(A1)
B1: $100 · B2: $50 · B3: =B1+B2
C1: #ff8833 · C2: #ff8833 · C3: =C1=C2
